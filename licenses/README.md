# License Copies

本目录保存随项目分发的第三方许可证副本：

- `GPL-2.0.txt`：Termux PRoot。
- `GPL-3.0.txt` 与 `LGPL-3.0.txt`：talloc 的 LGPLv3 条款包含并引用 GPLv3。
- `BSD-3-Clause-libandroid-shmem.txt`：libandroid-shmem 0.7。
- `Apache-2.0.txt`：Termux terminal-view/terminal-emulator 例外及 AndroidX 组件。
- `Termux-v0.118.0-LICENSE.md`：Termux v0.118.0 的仓库许可证和模块例外说明。

项目自身许可证位于仓库根目录的 [LICENSE](../LICENSE)。Ubuntu rootfs 中各软件包的许可证和版权声明保留在归档的 `/usr/share/doc/` 与 `/usr/share/common-licenses/` 中。
